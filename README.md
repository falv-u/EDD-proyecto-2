# EDD-proyecto-2

Segundo proyecto del ramo de Estructuras de Datos, el cual consiste en diseñar e implementar un sistema que simule el
funcionamiento de un juego de rol (RPG) en lenguaje C mediante listas enlazadas, pilas y colas.
